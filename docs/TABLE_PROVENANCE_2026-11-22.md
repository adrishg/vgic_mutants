### The three definitions

1. **Legacy "extreme atoms"** - the February 2026 vanilla tables on Hive

   LYS NZ, ARG NH1/NH2, ASN ND2/OD1, GLN NE2/OE1, ALA CB, GLY CA, and so on.
   Everything published on HuggingFace for vanilla Kv2.1 is this definition.
2. **Every non-hydrogen atom, backbone included** - all `masked_common99_50pct` tables,
   main and `_extra`, written 2026-11-19/20 by
   `scripts/kv21_distance_generation/generate_kv21_distance_shard.py`.
3. **Every non-hydrogen atom** again, for a second set of *vanilla* tables that exists
   only on the laptop: `26-02-10_*_vanillaAF2_distances_extra.csv`,

   them. They are a 2026-11-12 regeneration that kept the February file names.

### Answer to trap (c)

The discrepancy was read the wrong way round. **HuggingFace matches the raw Hive
export**; the local copies are the ones that differ, because they are definition 2/3
under a February name. Neither is miscomputed - each is correct for its own definition -
but only the published tables are the historical vanilla measurement, and only the
local ones are comparable with the masked `_extra` tables. `CA_*` columns are identical
in every copy.

In the data root the vanilla **main** QC tables
(`*_vanillaAF2_distances_all_ok_rmsd_3A_structural_interface_qc.csv`) are definition 1
and identical to HuggingFace (537 `shortest_*` columns, 0 differing), while the vanilla
**extra** QC tables are definition 3.
