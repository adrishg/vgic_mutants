# Archived seed-block outputs

This directory preserves the first seed-block revision for provenance. It is
not the source of the current Figures 4–7.

Two filenames retain obsolete terminology:

- `cav12_g402s_nearest_partner_seed_block.csv` is a historical within-G402S
  categorical masking summary. It is excluded from current outputs because a
  nearest candidate does not imply a ≤4 Å contact and does not estimate the
  WT–G402S sequence effect.
- `cav12_g406r_local_validity_seed_block.csv` predates the required wording.
  Its endpoint is only the selected **R406-centered overlap screen** and does
  not establish local or pocket validity.

Use `../paired_seed_v2/g402s_matched_ca_partner_statistics.csv` and
`../paired_seed_v2/g406r_screen_denominators.csv` for current results.
