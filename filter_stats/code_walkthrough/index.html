Follow one model through the pipeline

WT network 2, seed 1, at recycle 1 was built to be misfolded: every voltage sensor sits on its own pore domain instead of its neighbour's. Here is what each step does with it.

build_dv.pyIts spread is 10.61 Å. Spread is measured from the group's average model, which includes this one, so the other five WT models at recycle 1 read high too (2.16–2.33 Å), and the group's mean spread is 3.66 Å.
screen.pywiring = 0 of 4 voltage sensors on the right pore domain, so it fails and is removed (reason: wiring). The same prediction passes at recycle 2.
region_dv.pyWT recycle 1 is relabelled and refitted without it. Network 2 keeps 2 models (seeds 0, 2), each now with spread 0.47 Å. With two models, both sit the same distance from their mean.
stats.pyspread_VSD, R18Q vs WT at recycle 1: ratio 1.48, t = 14.0, but the cutoff is 72 with df = 1, so it is not significant (a limit of the tiny design).

The toy dataset

  • A made-up four-chain channel of 43 residues (chains A–D), drawn as a cartoon of a voltage-gated channel: each subunit's voltage sensor (S1–S4) sits next to its clockwise neighbour's pore domain (S5–S6).
  • 2 conditions: WT (the control) and the mutant R18Q (UniProt residue 18, in S4).
  • 2 networks (ColabFold model_1, model_2) × 3 seeds × recycles 0, 1, 2: 18 models per condition. A fourth seed of model 2 stopped early (no recycle 2), so it is left out.
  • A reference structure numbered UniProt + 100, missing residue 12, with an extra toxin chain E and waters and a calcium ion in chain W.
  • Built in: R18Q's voltage sensor is looser (more spread), network 2 has a small systematic error, and errors shrink with each recycle. WT model 2 seed 1 is misfolded at recycle 1 (every voltage sensor on its own pore domain), and omit.csv names R18Q model 1 seed 2 for removal by hand.
  • Everything was made by toy_data/make_toy_data.py; it is small enough to read on screen, not realistic.

The dataset is tiny so that every table fits on screen. That makes some numbers unrealistic, above all in stats.py, where 2 conditions and 2 networks leave 1 degree of freedom and nothing can reach significance.

Using a walkthrough

  • Next (or →) runs one statement and goes inside every function it calls; Back (or ←) undoes it.
  • Skip call runs the function about to be entered in one go; Finish function jumps to the value the current function returns.
  • Jump to lists every function call that is stepped through; clicking a line number goes to the next time that line runs.
  • Each page opens on its inputs and ends on the files it wrote.

Each page is one self-contained HTML file that works offline. The folder code_tutor/ beside the pipeline's files holds the toy data, the scripts that made these pages, and a README on rebuilding them or making one for another file.
