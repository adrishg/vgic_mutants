# CaV1.2 S6-gate screen

This optional analysis defines nested S6-gate mask windows around the four
full-length α1C gate centers (401, 749, 1182, and 1516). The reported mask
levels are fractions of the eight-residue local gate window, not fractions of
the whole protein:

- 25%: two positions per domain;
- 50%: four positions per domain;
- 100%: the complete eight-position window per domain.

The same sequence and prediction settings are used for each comparison. The
public repository retains the analysis description and downstream notebooks;
prediction inputs and generated structures remain in the versioned data
release.
