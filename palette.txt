CHANNEL / MUTANT / SETTING COLOR PALETTE
======================================

Source of truth: shared/plotting.py
This file is a reference copy of the shared palette.

Convention: lighter colors = vanilla; darker colors = masked.
Code suffixes: VAN = vanilla; HM = masked.
Channel families: Cav1.2 = blue; Kv2.1 = green; Nav1.5 = purple.
WT = wild type. Hex values are RGB colors for use in plotting/design tools.

IFM excluded means excluded from the mask, not deleted from the sequence.
QQQ_MASKED is an alias of QQQ_HM (#4E2B62), the original masked setting.
M2_VAN (#EBC9E3) and M2_HM (#8F3F75) are reserved colors for a second
mutant or alternative mask; no specific mutant is assigned to them here.
